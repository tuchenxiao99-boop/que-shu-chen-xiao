## 关键技术结论（写给下一个我）

- **mcp[cli]==2.0.0 里 FastMCP 没了**：改名 MCPServer，住址 `from mcp.server.mcpserver import MCPServer`；装饰器 `@mcp.tool()` 与 `mcp.run()`（stdio默认）用法不变。铁律再显灵：写代码前查当前版本API，别凭记忆
- **Cherry Studio 接 Moonshot**：CherryIN 自带额度为0（白嫖失败）；Tier0 免费档限速到 429 maxRetriesExceeded 不可用；**充值50解锁Tier1 是硬性门槛**；模型必须切到"月之暗面"分组（跟CherryIN是两户，竖线后面看爹）
- **API货架上没有kimi-k3**：App产品版与API开放型号是两套货架，K2.7 Code 工具调用完全够用
- **panel "Not connected"报错** = buttplug连接过期缓存，重启panel.py即清零；待办：给panel加断线自动重连（server.py已有_reset模式可抄）
