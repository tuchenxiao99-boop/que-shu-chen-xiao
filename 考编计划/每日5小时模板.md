# 每日时间模板（晚间纯净 3h 制）

> 时间口径（2026-09-10 核定）：17:00–18:00 下班，晚饭后 **19:30 左右坐到书桌前**。
> **19:30–22:30 晚间纯净 3h 是主战场、是军令**；23:00 前睡，留半小时洗漱缓冲。
> 早间背诵和白天碎片是加餐，不计入 3h 底线，做了是赚的。

## 主战场：晚间纯净 3h（19:30 → 22:30）

| 时段 | 动作 | 时长 |
|---|---|---|
| 19:30–20:50 | 职测模块攻坚（纸质题本+铅笔，当前阶段重点模块） | 80min |
| 20:50–21:00 | 休息：起来倒水、拉伸，不刷短视频 | 10min |
| 21:00–22:00 | 综应大题手写 / 框架背诵（手写是硬要求） | 60min |
| 22:00–22:30 | 当晚错题整理（不过夜）+ 写次日日程 | 30min |
| 23:00 | 睡。这条还是很凶，不收回。 | — |

- 顺序可按当天状态对调：脑子清醒先攻职测，脑子闷先背综应
- 盯晚自习的日子：盯班间隙的题本就是第一段，到家直接从第二段接
- 饭别吃太撑，七分饱，不然 19:30 那段是废的

## 碎片时间细则（白天加餐，每次 5–15min）

**总原则：碎片只刷「不用演算」的模块——常识、言语、策略选择；要动笔算的（资料分析、数量、判断推理的难题）留给晚间整块或盯班题本。**

| 场景 | 动作 | 隐蔽度 |
|---|---|---|
| 早读前 06:20–06:50 | 综应框架背诵（思维导图打印件夹进教案本） | ★★★ |
| 课间 5–10min | 粉笔APP「做题模式」一组 10 题：常识/言语/策略轮换；错题点收藏，不当场细看 | ★★★★★ |
| 午休前 10min | 翻手机相册错题截图 / APP错题本：只看错因，不重做 | ★★★★★ |
| 通勤 / 走路 | B站 D类刷题课当音频听（资料分析、判断推理方法论优先） | ★★★★★ |
| 排队 / 等饭 | APP 常识+政治理论 5 题快刷 | ★★★★★ |
| 晚自习盯班间隙 | **不算碎片**：纸质题本+铅笔，需要演算的模块放这里，远看像在改作业 | ★★★★ |

**错题流转**：APP 刷错的当场收藏或截图 → 当天 22:00 那段统一过解析 → 仍不懂的抄进错题本。
**介质分工**：综应永远手写（真题册+白纸）；职测碎片用 APP、整套模考用纸质模拟卷。

**办公室纪律**：备考一个字都别透。综应手写、教材、真题卷一律不进办公室；办公室里只有手机和「教案本」。

## 状态差的日子（内耗 / 疲惫）

- 晚间只做第一段 + 第二段的一半，即算守住底线，不许自责
- 连续两天这样，第三天「查库写日程」时主动说，日程会减量
- 办公室人际账白天翻篇，晚上的 3 小时是纯净区，不拿来反刍
- 同事是同事，前途是前途——她的未来不在那间办公室

## 周末

- 周日上午 08:30–12:00：完整模考（职测 90min + 综应 120min 连做，模拟真实节奏）
- 下午：复盘 2h——错题归因、下周弱项排期
- 晚上：休息。续航比冲刺重要。

## 早上仪式

她喊「查库写日程」→ 读 `README.md` + `40天冲刺计划.md` + 最近一条打卡 → 产出当日日程，格式：

```
日期 / 当前阶段 / 今日三件事 / 各时段任务表 / 一句鼓劲
```
