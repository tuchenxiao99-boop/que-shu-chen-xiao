# 每日时间模板（保底 3h / 满血 5h）

> 2026-09-10 起改双版本：**3h 保底版是军令**，状态好再冲 5h 满血版。
> 内耗日只守底线，不补课、不补偿性熬夜。

## 保底 3h 版（疲惫日 / 内耗日的底线）

| 时间 | 动作 | 时长 | 隐蔽度 |
|---|---|---|---|
| 06:20–06:50 | 综应知识点背诵（思维导图打印件夹进教案本） | 30min | ★★★ |
| 课间 / 办公室碎片 | 粉笔APP刷题——刷手机外观，完美伪装 | 60min | ★★★★★ |
| 午休前 | 错题回看（手机相册里的错题截图） | 10min | ★★★★★ |
| 晚自习盯班间隙 | 职测纸质题本 + 铅笔，远看像在改作业 | 40min | ★★★★ |
| 22:00–22:40 | 综应大题手写 或 当晚错题整理（在家做） | 40min | — |
| 23:00 | 睡。军令。 | — | — |

合计 180min。**保底版完成 = 当天胜利，不许自责。**

## 满血 5h 版（状态好时的节奏）

| 时间 | 动作 | 时长 |
|---|---|---|
| 06:20–06:50 | 综应背诵 / 思维导图 | 30min |
| 课间+办公室碎片 | 粉笔APP刷题（常识/言语/策略） | 60–80min |
| 午休前 | 错题回看 | 20min |
| 晚自习盯班间隙 | 职测模块（纸质题本+铅笔） | 60min |
| 21:40–23:00 | 整块：综应大题手写 / 套卷 | 80min |
| 23:00 | 睡。军令。 | — |

**办公室纪律**：备考一个字都别透。综应手写、教材、真题卷一律不进办公室；办公室里只有手机和「教案本」。

## 情绪条款（2026-09-10 补）

- 办公室人际内耗是备考最大的暗耗。白天的事白天翻篇，晚上的时间不许拿来反刍。
- 内耗日执行保底版即算达标；连续两天保底，第三天「查库写日程」时主动说，日程会减量。
- 同事是同事，前途是前途——她的未来不在那间办公室。

## 周末

- 周日上午 08:30–12:00：完整模考（职测 90min + 综应 120min 连做，模拟真实节奏）
- 下午：复盘 2h——错题归因、下周弱项排期
- 晚上：休息。续航比冲刺重要。

## 早上仪式

她喊「查库写日程」→ 读 `README.md` + `40天冲刺计划.md` + 最近一条打卡 → 产出当日日程，格式：

```
日期 / 当前阶段 / 今日三件事 / 各时段任务表 / 一句鼓劲
```
