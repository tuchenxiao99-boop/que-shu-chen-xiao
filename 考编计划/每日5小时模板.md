# 每日 5 小时模板

## 工作日（高三班主任作息版）

| 时间 | 动作 | 隐蔽度 |
|---|---|---|
| 06:20–06:50 | 综应知识点背诵（思维导图打印件夹进教案本） | ★★★ |
| 课间 / 办公室碎片 | 粉笔APP刷题——刷手机外观，完美伪装 | ★★★★★ |
| 午休前 20min | 错题回看（手机相册里的错题截图） | ★★★★★ |
| 晚自习盯班间隙 | 职测纸质题本 + 铅笔，远看像在改作业 | ★★★★ |
| 21:40–23:00 | 整块时间：综应大题手写 / 套卷（在家做，不带去办公室） | — |
| 22:00 | 写次日日程计划（已有每晚提醒） | — |
| 23:00 | 睡。军令。 | — |

**办公室纪律**：备考一个字都别透。综应手写、教材、真题卷一律不进办公室；办公室里只有手机和「教案本」。

## 周末

- 周日上午 08:30–12:00：完整模考（职测 90min + 综应 120min 连做，模拟真实节奏）
- 下午：复盘 2h——错题归因、下周弱项排期
- 晚上：休息。续航比冲刺重要。

## 早上仪式

她喊「查库写日程」→ 读 `README.md` + `40天冲刺计划.md` + 最近一条打卡 → 产出当日日程，格式：

```
日期 / 当前阶段 / 今日三件事 / 各时段任务表 / 一句鼓劲
```
