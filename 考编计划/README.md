## 纠偏结论（2026-10-11）

1. **粉笔D类资料没有白买**：它仍然对应湖北省事业单位联考、襄阳市直事业单位教师岗、武汉教育系统专项等D类考试。
2. **D类不能再当唯一主线**：2024—2026湖北省中小学教师统招均为《教育教学专业知识》70% +《综合知识》30%；襄阳市直学校单招近年常见学科专业知识 + 教育学、心理学。
3. **后续主线改为“英语学科 + 综合知识/教心 + D类支线”**，不是推翻重来，而是重新排优先级。
