## 关键情报（一句话版）

- 武汉中心城区高中岗基本要硕士 → 本科走义务段或聘用制；**高中编制的门在襄阳**（如市教育局直属学校单招，本科可报）。
- D类笔试：职测 90 分钟 100 题（常识/言语/判断/数量/策略选择），综应 120 分钟（辨析/案例分析/方案设计），两科连续 3.5 小时，各 150 分。
- 面试：武汉 = 结构化 + 无学生试讲；联考面试各地组织，多为试讲/说课/结构化。笔试面试各占 50%。
- 报名入口：湖北省人事考试网 rst.hubei.gov.cn/hbrsksw ｜ 武汉市人事考试院 whptc.org + 武汉数智人社 ｜ 省统招 nc.hbea.edu.cn ｜ 襄阳市人社局 rsj.xiangyang.gov.cn「招录招聘」专栏。
