# 资料分析 · 增长相关速记卡

> 沈确制 · 2026-09-17。依据粉笔《事业单位D类 职测（中学版）》教材「增长相关」粉笔小结整理。
> 用法：打印贴书桌前，碎片时间扫两眼；先背框架，再背公式，最后背百化分表。

## 一、三大块框架（先记这个）

```
增长相关
├── 增长率（一般 / 混合 / 间隔 / 年均）
├── 增长量（计算 / 比较）
└── 基期与现期（普通基期 / 间隔基期 / 基期和差 / 现期计算）
```

## 二、核心公式（背到条件反射）

| 场景 | 公式 / 口诀 |
|---|---|
| 一般增长率 | r =（现期 − 基期）÷ 基期 = 现期÷基期 − 1 |
| 间隔增长率 | r间 = r₁ + r₂ + r₁×r₂ |
| 混合增长率 | 混合后居中，偏向基期量较大的（线段法：距离与量成反比） |
| 年均增长率 | 基期 ×（1+r）ⁿ = 现期；n 相同，直接比 现期÷基期 |
| 增长量 | 增长量 = 现期 − 基期 = 现期÷(1+r) × r |
| 增长量速算（百化分） | r ≈ 1/n → 增长量 ≈ 现期÷(n+1)；减少量 ≈ 现期÷(n−1) |
| 基期量 | 基期 = 现期÷(1+r)｜｜r｜≤5% 化除为乘：≈ 现期×(1−r)；｜r｜>5% 截位直除 |
| 间隔基期 | 基期 = 现期 ÷（1 + r间） |
| 现期量 | 现期 = 基期 ×（1+r）= 基期 + 增长量 |

## 三、比较类秒杀

- **增长率比较**：现期/基期倍数关系明显 → 直接比「现期÷基期」；不明显 → 比「（现期−基期）÷基期」
- **增长量比较**：① 大大则大（现期量大、r 也大 → 增长量必大）；② 否则百化分
